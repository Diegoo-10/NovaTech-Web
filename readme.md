# NovaTech Solutions

Página web empresarial desarrollada como proyecto de portafolio.

## Descripción

NovaTech Solutions es una página web creada para presentar los servicios de una empresa ficticia de tecnología.

El proyecto incluye una sección de inicio, servicios, proyectos, información de la empresa y formulario de contacto.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Navegación entre secciones.
- Diseño responsive para dispositivos móviles.
- Animaciones al pasar el mouse sobre los proyectos.
- Botón de navegación hacia los servicios.
- Formulario de contacto con validación básica mediante JavaScript.

## Proyecto

Este proyecto forma parte de mi portafolio personal de desarrollo web y tiene como objetivo demostrar conocimientos en HTML, CSS y JavaScript.
